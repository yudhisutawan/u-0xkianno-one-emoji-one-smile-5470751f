One-emoji entry for make.fun's "One Emoji, One Smile" bounty ($5 prize pool, top 10). The program writes exactly one emoji — 🤗 U+1F917 HUGGING FACE, one character, 4 bytes UTF-8, no trailing newline — to `entry.txt`. It is the winner of a 10-candidate round-robin tournament (45 pairs, judged head-to-head with the competition's own judge brief): 9-0 undefeated. A smiling face with open arms offering a hug is the warmest gesture that still reads as friendly, universal and appropriate from a stranger — and it is chosen, not the first smiley that comes to mind.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Stdlib only; writes nothing into the repository itself. Verified with `python3 -S -P main.py` (grader-style: no site-packages).
